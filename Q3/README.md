# 问题 3：多时点光伏预报下的滚动购电调整

本 README 仅供人工阅读、核对和撰写论文时参考，不是可直接提交的论文版本；它是问题 3 唯一的总结文档。模型在每天 0:00 发布全天计划购电量，并在 6:00、12:00、18:00 获得新光伏预报后，只调整尚未执行的购电承诺。计划量高于调整量的部分按实时电价的 50% 支付违约费用，调整量高于计划量的部分按实时电价的 1.5 倍结算，缺电仍按 5 倍电价紧急购电。

## 模型与求解口径

采用带承诺版本台账的场景 MPC-MILP。公共购电承诺为 $q_t$，场景下的充电、放电、紧急购电、弃光和储电量分别为 $c_t^\omega,d_t^\omega,e_t^\omega,w_t^\omega,E_t^\omega$。每次发布新预测时求解

$$
q_t+G_t^\omega+d_t^\omega+e_t^\omega
=L_t+c_t^\omega+w_t^\omega,
$$

$$
E_{t+1}^\omega=E_t^\omega+0.9c_t^\omega-\frac{d_t^\omega}{0.9},
$$

并通过二元变量禁止同一时段充、放电。当前时刻的动作对全部场景相同，未来场景动作才允许分化，以满足非前视约束。相邻承诺版本的增减量为

$$
u_t=\max(q_t^{new}-q_t^{old},0),\qquad
v_t=\max(q_t^{old}-q_t^{new},0),
$$

实际现金费用由基线购电费、$1.5p_tu_t$、$0.5p_tv_t$ 和 $5p_te_t$ 构成。正式结果采用 24 小时前瞻、12 个历史残差场景和 `event-policy` 后端，1 月用于暖机，表格与费用仅覆盖 2 月 1 日至 12 月 31 日。

## 是否需要利用 6:00、12:00、18:00 的新预报

四个季节代表日的调整时刻消融结果如下。费用为四日平均值，只能说明代表日差异，不能外推为全年必然收益。

| 调整时刻 | 四日平均费用（元） | 相对不调整 |
|---|---:|---:|
| 不调整 | 31,645.32 | — |
| 6:00 | 31,269.12 | -1.19% |
| 12:00 | 31,849.20 | +0.64% |
| 18:00 | 30,467.77 | -3.72% |
| 6:00、12:00 | 31,509.20 | -0.43% |
| 6:00、18:00 | 29,974.79 | -5.28% |
| 12:00、18:00 | 30,467.77 | -3.72% |
| 6:00、12:00、18:00 | 30,116.44 | -4.83% |

据此，更新预报具有利用价值，但效果明显依季节和时点而异：三次全部调整的四日平均费用下降 4.83%，2 月 1 日却比不调整增加 415.51 元；四日平均最优组合是 6:00 与 18:00，而不是机械地使用全部时点。
