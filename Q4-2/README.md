# 问题4-2：波动电价下重算问题2

本目录把问题2的日初随机购电模型扩展到附件4的逐日、逐10分钟波动电价。
每天0:00只能使用此前已经发生的数据和当时已经发布的0:00实时电价；附件4当天
00:10以后的未来真实电价只用于事后结算，不进入当天的预测和计划决策。

## 模型口径

- Q4-2只读取附件2和附件4，不读取附件1。1月1日没有历史数据，负载和光伏使用零先验；
  之后沿用Q2的因果周周期方法，并且正式结果从2月1日开始。
- 电价预测：0:00-0:10使用0:00已经发布的实时电价；首日其余区间使用该报价作持续性预测，
  历史不足7天使用附件4此前均值，第8天起使用附件4上周同日价格。
- 净负荷和电价场景抽取同一个历史日的整日残差，保留二者的共同波动。
- 0:00的144段计划购电量在全部场景中共享；储能和应急量按场景响应。
- 实际运行按当天真实净负荷逐时因果调度，计划费按附件4真实电价结算，紧急电按其5倍结算。
- 允许为未来保留电池并在当前购买紧急电；紧急电不能用于充电。
- SOC合法范围为1200–10800 kWh。仅对不超过1e-5 kWh的边界浮点毛刺钳位，真实越界报错。
- 时间列保持附件的跨日含义：本行末列属于下一日0:00，不能在本行循环移动。

## 命令

从仓库根目录运行单日单场景冒烟：

```powershell
python Q4-2/src/run_problem42.py --mode smoke --scenarios 1
python Q4-2/src/verify_problem42.py Q4-2/output/smoke_solution.npz
```

正式全年计算及结果文件生成：

```powershell
python Q4-2/src/run_problem42.py --mode full
python Q4-2/src/make_results.py
python Q4-2/src/verify_problem42.py
```

`full`会从2025-01-01开始传递SOC，并仅将2025-02-01至12-31的334天写入正式NPZ和Excel。
全年计算量较大；`smoke`不能生成正式`result4-2.xlsx`。

## 输出

- `output/prob4-2_solution.npz`：全年正式数值结果（完成full后生成）。
- `output/result4-2.xlsx`：按附件5模板生成的正式结果。
- `output/smoke_solution.npz`：单日冒烟结果，不能冒充全年结果。
