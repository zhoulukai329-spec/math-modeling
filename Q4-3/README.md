# 问题 4-3：波动电价下重算问题 3

本 README 仅供人工阅读、核对和撰写论文时参考，不是可直接提交的论文版本；它是问题 4-3 唯一的总结文档。模型沿用问题 3 的 0:00 基线计划与 6:00、12:00、18:00 修订机制，同时把附件 4 的动态电价纳入价格预测、场景生成和逐版本结算。

## 模型与信息边界

模型采用光伏—电价联合残差场景的滚动 MPC-MILP。光伏预测来自附件 3，未来电价依次使用上周同一时段、历史同槽均值和首日边界先验；当前十分钟开始时才读取该格真实负荷、光伏和电价，未来真实值只用于事后结算。相邻版本上调、下调和紧急购电仍分别按实时价格的 1.5、0.5 和 5 倍计费。

核心约束为

$$
q_t+G_t^\omega+d_t^\omega+e_t^\omega
=L_t+c_t^\omega+w_t^\omega,
$$

$$
E_{t+1}^\omega=E_t^\omega+0.9c_t^\omega-\frac{d_t^\omega}{0.9},qquad
1200\le E_t^\omega\le10800.
$$

正式结果采用 24 小时前瞻、12 个联合历史场景和 `event-policy` 后端，1 月用于暖机，输出期为 2 月 1 日至 12 月 31 日。

## 前瞻与算法对照的解释边界

12、18、24 小时前瞻的代表日敏感性结果保存在 `analysis/horizon_sensitivity.csv`；`rolling-milp` 与 `event-policy` 的单日精度、速度对照保存在 `analysis/backend_comparison.csv`。这些结果分别检验前瞻长度和求解后端，不是对 6:00、12:00、18:00 调整时点的消融。因此本小题只报告既定三次修订机制下的波动电价重算结果，不重复评价各调整时点是否必要。

## 结论与证据

正式结果覆盖 48,096 个十分钟区间，总现金费用为 15,903,816.04 元，其中基线购电费 13,296,985.79 元、上调费 582,908.73 元、下调违约费接近 0、紧急购电费 2,023,921.52 元。动态电价下，计划量与储能动作会随价格预报改变，不能直接复用问题 3 的固定电价调度。
