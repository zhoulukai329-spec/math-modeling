# 问题 1：固定电价下的日内计划购电

本 README 仅供人工阅读、核对和撰写论文时参考，不是可直接提交的论文版本；它是问题 1 唯一的总结文档。题目要求在每天 0:00 制定当天计划购电策略，在满足负荷、储能容量与充放电功率约束的同时，使全天购电费最小，并保证 0:00 与 24:00 的储电量相同。

## 模型

将一天划分为 144 个 10 分钟时段，令 $x_t,c_t,d_t,w_t,E_t$ 分别表示计划购电量、充电量、放电量、弃光量和储电量，单位均为 kWh。电价 $p_t$、负荷电量 $L_t$ 和光伏电量 $G_t$ 已知，目标函数为

$$
\min \sum_{t=1}^{144} p_t x_t.
$$

约束为

$$
x_t+G_t+d_t=L_t+c_t+w_t,
$$

$$
E_{t+1}=E_t+0.9c_t-\frac{d_t}{0.9},
$$

$$
1200\le E_t\le10800,\qquad
0\le c_t,d_t\le\frac{5000}{6},\qquad
E_0=E_{144}=6000.
$$

目标与约束均为线性关系，因此采用线性规划直接求全局最优解。效率损失使无意义的同时充放电不会改善目标值；弃光变量用于保证光伏富余时模型仍可行。

## 结果解释与检验

无储能时全天购电量为 61,789.94 kWh、购电费为 48,052.05 元；采用储能后购电量降至 59,482.70 kWh，购电费减少 12,925.20 元，节费率为 26.90%。储能在低价或光伏富余时充电，在高价时放电，同时将 0:00 与 24:00 的储电量固定为 6,000 kWh，避免把跨日能量变化误计为收益。
