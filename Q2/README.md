# 问题 2：含紧急购电的日前随机调度

本 README 仅供人工阅读、核对和撰写论文时参考，不是可直接提交的论文版本；它是问题 2 唯一的总结文档。题目要求每天 0:00 制定全天计划购电量；实际净负荷超过计划供电能力时，可按实时电价的 5 倍紧急购电。除紧急购电费外，正常购电按全天计划量结算。

## 模型与求解口径

模型采用“因果预测 + 两阶段随机线性规划 + 逐时回测”。第一阶段在 0:00 确定公共计划购电量 $g_t$；第二阶段针对历史残差场景安排充电 $c_{s,t}$、放电 $d_{s,t}$、弃光 $w_{s,t}$、紧急购电 $e_{s,t}$ 和储电量 $E_{s,t}$。目标是最小化

$$
\sum_t p_tg_t+\mathbb E_s\!\left[\sum_t5p_te_{s,t}\right],
$$

并满足

$$
g_t+G_{s,t}+d_{s,t}+e_{s,t}=L_{s,t}+c_{s,t}+w_{s,t},
$$

$$
E_{s,t+1}=E_{s,t}+0.9c_{s,t}-\frac{d_{s,t}}{0.9},qquad
1200\le E_{s,t}\le10800.
$$

单时段最大充、放电量均为 $5000/6=833.33$ kWh，紧急购电只补当前负荷缺口，不能用于给储能充电。负荷与光伏分开预测；滚动检验中“上周同日同时段”的 MAE 为 327.77 kW、RMSE 为 486.47 kW，优于另外三种候选规则，因此用作点预测基础，并由最近 28 天残差生成场景。
